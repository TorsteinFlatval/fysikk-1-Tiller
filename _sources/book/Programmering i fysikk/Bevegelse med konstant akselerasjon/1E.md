## Iterasjon

Hvis vi ønsker å gange sammen to tall, for eksempel $3\cdot33$, kan vi legge $0$ og $3$ sammen til $3$:

$0+3=3$

Dette kalles første **iterasjon**. Deretter legger vi til 3 igjen:

$3+3=6$

Dette er andre iterasjon. Hvis vi itererer 33 ganger, vil vi til slutt få svaret:

$96+3=99$

Dette virker veldig tungvint, men for en datamaskin er dette mye mer effektivt enn å lage regler og steg for hvordan man ganger sammen to tall. Det finnes også tilfeller hvor vi ikke kan bruke formler direkte for å finne et svar, og vi blir nødt til å programmere for å finne ut svaret.

## Bevegelse med konstant fart

Vi ser på en gjenstand som beveger seg med konstant fart. Da vet vi fra veiformelen $s = v \cdot t$ at posisjonen endrer seg lineært med tiden, men her skal vi regne det ut steg for steg med et program i stedet for en formel.

Vi starter med å definere noen variabler som beskriver bevegelsen: farten `v`{l=python}, startposisjonen `s`{l=python} og starttiden `t`{l=python}.

Variabelen `dt`{l=python} bestemmer hvor store tidssteg vi skal gå fremover, og `t_slutt`{l=python} bestemmer etter hvor lang tid simuleringen skal stoppe.

:::{code-block} python
---
linenos:
---
v = 5.0  # farten til gjenstanden, m/s
s = 0.0  # startposisjon, m
t = 0.0  # starttid, s

dt = 0.1       # lengde på tidssteg, s
t_slutt = 3.0  # sluttid for simulering, s
:::

:::{explore} Utforsk 1
Hvor mange ganger tror du en løkke må kjøre for å komme fra `t = 0.0`{l=python} til `t_slutt = 3.0`{l=python}, dersom tidsstegene er `dt = 0.1`{l=python}? Tenk gjennom dette selv før du går videre.
:::

### Bruk av `while`{l=python}-løkke

For å regne ut posisjonen etter hvert tidssteg bruker vi en `while`{l=python}-løkke. Så lenge tiden `t`{l=python} er mindre enn `t_slutt`{l=python}, gjør `while`{l=python}-løkken to ting:

* Den regner ut den nye posisjonen ved å legge til strekningen gjennomsnittsfarten har tilbakelagt i løpet av tidssteget: `s = s + v*dt`{l=python}.
* Den øker tiden med ett tidssteg: `t = t + dt`{l=python}.

:::{code-block} python
---
linenos:
---
while t < t_slutt:
  s = s + v*dt  # beregner ny posisjon
  t = t + dt    # tiden økes med dt
:::

:::::::::::::::{example} Eksempel 1: Bevegelse med konstant fart
En ball beveger seg med en konstant fart på $v = 5$ m/s. Hvor langt kommer ballen på $3,0$ s?

:::{code-block} python
---
linenos:
---
# Programmet beregner tilbakelagt strekning for
# en gjenstand som beveger seg med konstant fart

# Informasjon om bevegelsen
v = 5.0  # farten til gjenstanden, m/s
s = 0.0  # startposisjon, m
t = 0.0  # starttid, s

# Simuleringsteknisk
dt = 0.1       # lengde på tidssteg, s
t_slutt = 3.0  # sluttid for simulering, s

# Løkka regner ut ny posisjon for hvert tidssteg
while t < t_slutt:
  s = s + v*dt  # beregner ny posisjon
  t = t + dt    # tiden økes med dt

# Skriver ut resultatet
print("t =", t, " s =", s, " v =", v)
:::

Dette programmet skriver ut:
```text
t = 3.0000000000000013  s = 15.0  v = 5.0
```

Grunnen til at `t`{l=python} får så mange desimaler, er hvordan desimaltall plusses sammen i datamaskiner, og vi kan skrive `t`{l=python} med bare 1 desimal ved hjelp av `round()`{l=python}-funksjonen:

:::{code-block} python
# Skriver ut resultatet med avrundet tid
print("t =", round(t, 1), " s =", s, " v =", v)
:::

Dette vil gi følgende utskrift:
```text
t = 3.0  s = 15.0  v = 5.0
```

## Lister

Så langt har vi bare vært interessert i posisjonen etter at simuleringen er ferdig. Men ofte vil vi vite hvordan posisjonen har endret seg gjennom hele bevegelsen, for eksempel for å tegne en posisjonsgraf. Da må vi lagre verdien av `s`{l=python} for hvert tidssteg, ikke bare den siste verdien.

Til dette bruker vi en **liste**. En liste i Python er en samling av verdier, skrevet med hakeparenteser `[ ]`{l=python} og komma mellom hvert element:

:::{code-block} python
---
linenos:
---
tall = [1, 2, 3, 4]
print(tall)
:::

For å legge til en ny verdi på slutten av en liste bruker vi metoden `.append()`{l=python}:

:::{code-block} python
---
linenos:
---
tall = [1, 2, 3]
tall.append(4)
print(tall)  # blir [1, 2, 3, 4]
:::

:::::::::::::::{example} Eksempel 2: Lister

Vi har en tom liste med tidsverdier, `tidsverdier = []`{l=python}. Vi ønsker å legge til verdiene 1 og -4.

<br> Da bruker vi `append()`{l=python}-funksjonen:

:::{code-block} python
---
linenos:
---
tidsverdier = [] # lager en tom liste
tidsverdier.append(1) # legger til tallet 1
print(tidsverdier) # skriver ut listen
tidsverdier.append(-4) # legger til tallet -4
print(tidsverdier) # skriver ut listen igjen
:::

Dette programmet skriver ut:
```text

[1, -4]
```

## Bevegelse med konstant akselerasjon

Nå kan vi bruke lister til å lagre bevegelsen til en gjenstand som akselererer, slik at vi kan tegne en graf etterpå. Dersom akselerasjonen `a`{l=python} er konstant, må vi oppdatere farten for hvert tidssteg med `v = v + a*dt`{l=python}, og deretter bruke den nye farten til å oppdatere posisjonen med `s = s + v*dt`{l=python}.

Vi starter med to lister som bare inneholder startverdiene, `t_verdier = [t]`{l=python} og `s_verdier = [s]`{l=python}. <br> Siden `t = 0`{l=python} og `s = 0`{l=python}, vil `t_verdier = [0]`{l=python} og `s_verdier = [0]`{l=python}. <br>
For hvert tidssteg i løkka legger vi så til den nye verdien av `t`{l=python} og `s`{l=python} med `.append()`{l=python}:

:::{code-block} python
---
linenos:
---
s = 0.0  # startposisjon, m
v = 5.0  # startfart, m/s
a = 2.0  # akselerasjon, m/s^2
t = 0.0  # starttid, s

t_slutt = 3.0
dt = 0.1
t_verdier = [t]
s_verdier = [s]

while t < t_slutt:
  v = v + a*dt         # beregner ny fart
  s = s + v*dt         # beregner ny posisjon
  t = t + dt           # tiden økes med dt
  t_verdier.append(t)  # legger t inn i tidslisten
  s_verdier.append(s)  # legger s inn i posisjonslisten
:::

:::{explore} Utforsk 4
Før løkka starter, er `v = 5.0`{l=python} og `a = 2.0`{l=python}. Hva blir `v`{l=python} etter at koden `v = v + a*dt`{l=python} kjøres én gang, med `dt = 0.1`{l=python}? Regn ut svaret selv, og test det deretter i koden under.
:::

### Tegning av graf

Når vi har listene `t_verdier`{l=python} og `s_verdier`{l=python} klare, kan vi tegne en graf med biblioteket `matplotlib.pyplot`{l=python}. Da må vi først importere biblioteket med `import matplotlib.pyplot as plt`{l=python} øverst i programmet. Siden vi skriver `as plt`{l=python}, slipper vi å skrive hele `matplotlib.pyplot`{l=python} videre.

:::{code-block} python
---
linenos:
---
plt.plot(t_verdier, s_verdier)              # lager grafen
plt.title("Strekning som funksjon av tid")  # tittel på grafen
plt.xlabel("$t$ (s)")                       # x-akse-tittel, $ gir kursiv
plt.ylabel("$s$ (m)")                       # y-akse-tittel
plt.grid()                                 # legger til rutenett
plt.show()                                 # viser grafen
:::

Prøv å kjøre hele programmet under.

:::{interactive-code}
import matplotlib.pyplot as plt

s = 0.0
v = 5.0
a = 2.0
t = 0.0
t_slutt = 3.0
dt = 0.1
t_verdier = [t]
s_verdier = [s]

while t < t_slutt:
  v = v + a*dt
  s = s + v*dt
  t = t + dt
  t_verdier.append(t)
  s_verdier.append(s)

plt.plot(t_verdier, s_verdier)              # lager grafen
plt.title("Strekning som funksjon av tid")  # tittel på grafen
plt.xlabel("$t$ (s)")                       # x-akse-tittel, $ gir kursiv
plt.ylabel("$s$ (m)")                       # y-akse-tittel
plt.grid()                                 # legger til rutenett
plt.show()                                 # viser grafen
:::

Dersom vi i stedet tegner farten `v`{l=python} som funksjon av tiden, blir grafen en rett linje, siden farten øker med samme mengde for hvert like store tidssteg.

:::{interactive-code}
import matplotlib.pyplot as plt

s = 0.0
v = 5.0
a = 2.0
t = 0.0
t_slutt = 3.0
dt = 0.1
t_verdier = [t]
v_verdier = [v]

while t < t_slutt:
  v = v + a*dt
  s = s + v*dt
  t = t + dt
  t_verdier.append(t)
  v_verdier.append(v)

plt.plot(t_verdier, v_verdier)              # lager grafen
plt.title("Fart som funksjon av tid")       # tittel på grafen
plt.xlabel("$t$ (s)")                       # x-akse-tittel, $ gir kursiv
plt.ylabel("$v$ (m/s)")                     # y-akse-tittel
plt.grid()                                 # legger til rutenett
plt.show()                                 # viser grafen
:::
